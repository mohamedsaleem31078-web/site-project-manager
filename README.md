# مِعمار - إدارة المشروع والموقع

تطبيق ويب أولي باللغة العربية لإدارة مشاريع الموقع وملاحظات العيوب (Snags)، بواجهة RTL وقاعدة بيانات SQLite محلية.

## التشغيل

يتطلب .NET 10 SDK. من مجلد `src/SiteProjectManager` شغّل:

```sh
dotnet restore
dotnet run
```

افتح عنوان `http://localhost:...` أو `https://localhost:...` الذي يعرضه الأمر في المتصفح. تنشأ قاعدة البيانات `site-project-manager.db` محليًا في مجلد التشغيل.

## الموجود حاليًا

- لوحة تحكم عربية.
- إنشاء المشاريع وملاحظات الموقع.
- اختيار الأولوية وتحديث حالة الملاحظة.
- حفظ البيانات محليًا في SQLite.

## ما لم يُنفذ بعد

رفع الصور وPDF والتأشير عليها، التقارير والخطابات القابلة للتصدير، النسخ الاحتياطي والاستعادة، تسجيل الدخول، المزامنة بين الأجهزة، ومساعد الذكاء الاصطناعي. هذا نموذج أولي وليس إصدارًا إنتاجيًا مختبرًا. لا تعرضه للإنترنت العام؛ لا توجد به حاليًا مصادقة مستخدمين أو صلاحيات. تغييرات قاعدة البيانات في هذه المرحلة تستخدم `EnsureCreated`؛ قبل توزيع تحديثات مستقبلية يجب إضافة EF Core migrations واختبار ترحيل البيانات والنسخ الاحتياطي والاستعادة.

## ملاحظة عن الإنترنت والعمل دون اتصال

البيانات الأساسية تحفظ على الجهاز الذي يشغّل التطبيق. الصفحة تحتاج أن يكون التطبيق المحلي مشغّلًا ويمكن الوصول إليه من المتصفح. لا توجد مزامنة سحابية أو PWA للعمل دون اتصال حتى الآن، كما أن ميزات الذكاء الاصطناعي تتطلب خدمة إنترنت عند تنفيذها.
