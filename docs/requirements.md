# Project Plan

## Phase 1: Foundation
- Define product scope
- Create initial repository structure
- Establish data model
- Start API project and DB design

## Phase 2: Core features
- Project CRUD
- Snag CRUD
- Attachment support
- Severity and status tracking
- Search and filters

## Phase 3: Presentation and reporting
- Dashboard screens
- Project summary screens
- Report generation
- Excel/PDF prepares

## Phase 4: Client communication
- Letter templates
- Formal client-facing text generation
- Export to PDF and print

## Phase 5: Stability and operations
- Backup/restore flow
- Data validation
- Local persistence and recovery

## Phase 6: AI enhancement
- Improve letter text and summaries
- Draft formal messages for client communication
- Suggest clearer project reports

## Recommended technical direction

- ASP.NET Core app for the main application
- SQLite for local data storage
- Web-first architecture for stability and speed
- Future desktop packaging if needed
